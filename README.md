StrangeCode AI Agent 🤖

A beginner-friendly AI agent built with Python to learn how AI agents work and interact with Large Language Models (LLMs).

Features
Accepts user input and generates AI responses.
Uses the OpenAI API.
Simple and easy-to-understand code.
Technologies
Python
OpenAI API
Installation
Clone the repository:
git clone https://github.com/Strangerfuture/strangeCode

Navigate to the project folder:
cd strangeCode

Install the required package:
pip install openai

Set your OpenAI API key as an environment variable:
export OPENAI_API_KEY="your-api-key"

Run the project:
python main.py

Learning Goals
Understand the basics of AI agents.
Learn how to integrate an LLM using an API.
Explore prompt engineering and response generation.
